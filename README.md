# Lunettes Intelligentes pour Malvoyants

## Description
Dispositif d'assistance embarqué basé sur Arduino pour aider les aveugles dans leurs déplacements. Les lunettes utilisent un capteur ultrason pour détecter les obstacles en temps réel et avertir l'utilisateur par un signal sonore.

## Fonctionnement
* Measurement continue de la distance des obstacles en face de l'utilisateur.
* **Détection (< 50 cm) :** Activation immédiate du buzzer/vibreur pour avertir du danger.
* **Zone libre (>= 50 cm) :** Aucun signal.

## Composants matériels
* Carte Arduino 
* Capteur ultrason (HC-SR04)
* Buzzer 
* Batterie / Alimentation
